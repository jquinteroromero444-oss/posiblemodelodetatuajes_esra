# Cristal Yum | Tatuajes de Autor & Microblading

Sitio web oficial de **Cristal Yum Studio** en Albolote (Granada).

- **Tatuajes de Autor:** Estilo botánico, neo-japonés, línea fina y sombras suaves.
- **Microblading Hiperrealista:** Reconstrucción pelo a pelo y armonía facial.
- **Ilustraciones Personalizadas:** Láminas de autor y técnica de grabado tradicional.
- **Joyería & Artesanía:** Piezas exclusivas en plata de ley y gema obsidiana.

## Tecnologías
- HTML5 semántico
- Tailwind CSS (diseño responsivo, modo oscuro integral)
- Tipografías: Playfair Display & Plus Jakarta Sans
- Iconografía: Google Material Symbols
